# Datasets

This folder contains small sample datasets used across the bootcamp modules.
Larger datasets are downloaded programmatically inside the notebooks (e.g., from `sklearn.datasets` or Kaggle).

## Available Datasets

| File | Description | Used In |
|------|-------------|---------|
| `sample_regression.csv` | Synthetic regression dataset (house size vs. price) | Module 04 |
| `sample_classification.csv` | Synthetic classification dataset (two classes) | Module 05 |
| `sample_clustering.csv` | Synthetic clustering dataset (three clusters) | Module 07 |

## Generating Datasets

Each notebook also shows how to generate or download the dataset it uses, so you can always reproduce the data from scratch.
